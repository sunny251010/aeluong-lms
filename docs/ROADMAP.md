# Roadmap

## Phase hien tai: Phase 0 - Khoi tao source control

Muc tieu truoc mat la dua du an vao Git mot cach an toan:

- Tao `.gitignore` de tranh dua WordPress core, config local, uploads va cache len repo.
- Tao bo docs nen cho kien truc, data model va roadmap.
- Khoi tao Git repo local.
- Cho remote URL truoc khi push len GitHub/Git server.

## Phase tiep theo de xuat

- Phase 1: Tao plugin rieng cho LMS logic.
- Phase 2: Dinh nghia data model LMS va admin UI co ban.
- Phase 3: Xay course/lesson workflow.
- Phase 4: Enrollment, progress tracking va dashboard hoc vien.

## Ghi chu

- Khong tu them dependency neu chua can.
- Khong commit/push cac file nhay cam hoac generated artifacts.
- Cap nhat roadmap moi khi doi phase hoac them milestone quan trong.
